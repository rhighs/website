# Token source

The document surface uses the default tokens emitted by `@imd/react`: `full-black` ground and `book` typeface.

# Site shell bridge

- Ground: `#000000`
- Ink: `#f4f4f5`
- Muted: `#949499`
- Control: `#26262a`
- Accent: `#6ea8ff`
- Prose: `"Source Serif 4", "Iowan Old Style", Charter, Georgia, "Times New Roman", serif`
- Labels: `"Inter Tight", "Inter", "Helvetica Neue", Helvetica, Arial, sans-serif`
- Mono: `"JetBrains Mono", "SF Mono", ui-monospace, Menlo, Consolas, monospace`
- Spacing step: `5px`

The shell mirrors these values only for content outside `.imd-document`. It does not override IMD component tokens.

# Editorial artwork

- Paper: warm off-white handmade watercolor stock
- Primary ink: cobalt and ultramarine
- Secondary ink: deep teal
- Rare signal: vermilion orange
- Motif: capillary branching, cellular diffusion, biological-computational structures
